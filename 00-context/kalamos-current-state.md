## Stato tecnico (cosa serve costruire)

### MVP minimo per credibilità in colloquio PLAI

1. **Web UI** (anche minimale): upload manoscritto → output scheda di lettura strutturata
2. **Backend AI pipeline**: estrazione testo → analisi (sintesi, qualità, target, comparable) → output strutturato
3. **Dashboard editor**: vista batch di manoscritti con scoring e fit per collana
4. **Demo data set**: 10-20 manoscritti pubblici (es. classici fuori copyright, o testi inventati di qualità varia) per dimostrare la pipeline live

**Tempo realistico per costruirlo**: 3-4 settimane di lavoro intenso con stack moderno (Next.js + Claude API + Postgres + Vercel). Fattibile prima di un eventuale colloquio.
