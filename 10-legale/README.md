# Legale

Bozze di lavoro per i piloti con le case editrici. **Nessuna va firmata o pubblicata come definitiva prima della revisione di un avvocato abilitato**; ogni file elenca in fondo i punti da fargli validare.

| File | Cosa contiene |
|---|---|
| `dpa-pilota.md` | Nomina di Kalamos a responsabile del trattamento (art. 28 GDPR), da firmare con la casa editrice prima di ricevere qualunque manoscritto |
| `nda-pilota.md` | Accordo di riservatezza bilaterale per valutare e svolgere il pilota |
| `revisione-informativa.md` | Confronto di `/privacy` con l'art. 13 GDPR: cosa è stato corretto, cosa resta da decidere |

Le versioni `.docx` nella stessa cartella sono generate dai `.md` con `npm run legale:docx`, per la revisione con le modifiche tracciate. Il testo di riferimento resta il `.md`.
